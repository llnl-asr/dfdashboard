DFDashboard
===========

The interactive visualization layer of the DataFlowX suite: a FastAPI and
SolidJS dashboard for exploring DFTracer trace files (``.pfw`` / ``.pfw.gz``),
backed by the dftracer-utils C++ index so it stays responsive on large traces.
